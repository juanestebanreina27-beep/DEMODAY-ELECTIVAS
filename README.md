# STABLE - Premium Visual Intelligence Landing Page

This is a high-fidelity recreation of the STABLE landing page, built using modern web technologies and following the premium design principles of the `taste-skill` repository.

## Project Overview

The project features:
- **Immersive 3D Visuals:** Interactive 3D distorted torus powered by React Three Fiber and Three.js.
- **Glassmorphic Design:** Modern UI components with blur effects, translucent backgrounds, and precise borders.
- **Advanced Animations:** Scroll-triggered reveals and staggered motion using Framer Motion.
- **Premium Aesthetics:** Global film grain noise texture and a carefully selected dark-mode color palette.
- **Responsive Layout:** Fully responsive sections including Hero, Features, Capabilities, and CTA.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS 4.0
- **3D Engine:** React Three Fiber / Three.js
- **Animation:** Framer Motion
- **Icons:** Lucide React
- **Language:** TypeScript

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Design Principles

This project adheres to the "Anti-Slop" design rules:
- Minimalist typography-first approach.
- Generous whitespace and "breathing room".
- High-contrast, monochromatic color schemes.
- Organic motion and 3D interactions.
